## Overview
This project monitors real-time health vitals (Heart Rate, SpO2, Temperature) and detects anomalies using AI.

- Trained on 1000 synthetic patient records
- Algorithm: Isolation Forest (contamination=0.05)
- Real-time alert for critical values

## Tech Stack
Python, Pandas, Scikit-Learn

## How to Run
pip install pandas scikit-learn
python final_project.py
